Design engineer and creative developer. I design something and then build the production version of it myself:
React, TypeScript, and real-time 3D on the web.

For the last three years I have been the sole developer on a production platform at Soquelec Group, a bilingual

### What's here

**[face-to-voice](https://github.com/OliverA100/face-to-voice)** ([facetovoice.com](https://facetovoice.com))
Shape a realistic 3D head, hear the voice it suggests, then talk to it live. Google's GNM morphable model in
React Three Fiber, GPU strand hair, Claude for casting, ElevenLabs Voice Design, and a LiveKit agent for live
conversation with lip sync driven by per-character timestamps. TypeScript, Python pipeline, MIT.

**[the-pokemon-wall](https://github.com/OliverA100/the-pokemon-wall)** ([demo](https://the-pokemon-wall.vercel.app/))
A searchable WebGL wall of all 1,025 Pokemon. Scrolls sideways, bends as you move, and stays keyboard and
screen-reader accessible. TypeScript, Three.js, custom GLSL.
